## 发现

### W1 云相册加载失败无重试入口（P1，已修）
- 位置：`Views/CloudPage.xaml` 浏览卡片、`ViewModels/CloudViewModel.Album.cs`
- 证据：`LoadAlbumAsync` 捕获异常后只写 `AlbumStatus`，页面没有错误组件；用户只能再点一次「刷新」且不知道是否在重试。
- 实际→预期：失败仅灰字 → 失败时出现错误条（原因 + 重试按钮），重试保留当前目录。
- 影响：断网/密码失效时用户不知道下一步；属于核心旅程失败恢复缺口。
- 修复：`AlbumError/AlbumHasError` + InfoBar（Severity=Error，"重试"复用刷新）；成功清空。
- 复验：云相册断网点刷新 → 错误条出现；恢复网络点「重试」→ 列表回来且仍在原目录。

### W2 「下载到素材库」无前置条件（P1，已修）
- 位置：`CloudPage.xaml` 按钮组
- 证据：按钮一直可点，没勾选时点了只得到"先勾选要下载的文件"的状态文字。
- 预期：无勾选禁用；有勾选可用。
- 修复：`AlbumHasSelection` 绑定 `IsEnabled`；提示改为 tooltip「先勾选云端文件」。
- 复验：进入目录未勾选 → 按钮灰；勾 1 项 → 可点。

### W3 上传入口的前置条件与内容不可见（P2，已修）
- 证据：「上传所选素材」没有说明"先在素材库选中"，也没说明会带 XMP。
- 修复：tooltip 补「先在素材库选中素材（会连同 XMP 边车一起上传）」。
- 复验：hover 显示说明。

### W4 长错误文本撑开布局（P2，已修）
- 证据：`AlbumStatus` 是 `TextWrapping="Wrap"` 无行数限制，云异常可带很长的 URL。
- 修复：`MaxLines=2` + `TextTrimming=CharacterEllipsis`；完整信息保留在日志与错误条 Message。
- 复验：制造 500 字符错误串，卡片高度不跳。

### W5 刷新只能点按钮（P2，已修）
- 证据：无键盘快捷键；`ui-walkthrough` 键盘路径项未覆盖。
- 修复：`RefreshButton.KeyboardAccelerators` 增加 F5。
- 复验：任意页面按 F5 → 顶栏进度条出现并完成。

### W6 键鼠焦点与读屏（P2，未验证）
- 证据：仅抽查主要按钮有 AutomationProperties；网格卡片/筛选面板未逐项核对焦点顺序、Name、LiveRegion。
- 状态：未验证，不声称已达标；列入完整审查任务：`LibraryPage`、`InspectorPanel`、`CloudPage`、`SettingsPage` 逐控件补 Name/焦点顺序，扫描/同步状态用 LiveRegion 播报。

### W7 缩放与窄窗（P2，未验证）
- 证据：布局用自适应列 + 侧栏折叠阈值（<1000 折叠筛选、<1280 折叠检视），但未在 200% 缩放/最小窗口实测文字截断。
- 状态：未验证。建议复验：1366×768、200% 缩放、窗口宽 900。

### W8 文案一致性（P3，部分修）
- 证据：云相册/云同步并存期间出现过「云同步」「云相册」混用；本次统一页面标题为「云相册」，原同步卡片保留但说明"云相册包含同步"。
- 待办：全量字符串扫描（`grep` 中文硬编码）逐条入词表；错误提示统一"发生了什么/可做什么/重试"。
