# 页面 / 入口 / 交互地图（frontend-to-ue 适配版）

> `frontend-to-ue` 面向"把 HTML 前端转成可缩放可搜索的 UE 地图"。本项目是原生应用（WinUI 3 / Compose / SwiftUI），
> 没有前端路由和可运行网页，因此按该技能的**信息结构**（页面 → 入口 → 交互 → 跳转）产出文字版地图；
> 后续如需可视化，可用同一份数据生成 HTML 地图。

## 顶层导航

| 平台 | 顶层入口 | 说明 |
| --- | --- | --- |
| Windows | 侧栏：素材库 / 云相册 / 影像合集 / 地图 / 时间线 / 导入 / 重复项 / 转码 / LUT / 水印 / 设置 | 云相册 = 浏览 + 原云同步 |
| Android | 素材库（含详情 Sheet、筛选 Sheet、批量 Sheet）+ 顶栏云相册 + 设置 | 移动端只保留"看/筛/改/取/传" |
| macOS | 侧栏：素材库 / 云相册 / 设置 等 | 以 macOS 仓库为准 |

## Windows

```
素材库 LibraryPage
├─ 顶栏：搜索 / 扫描（选目录）/ 刷新(F5) / AI 队列 / 主题
├─ 左：筛选面板（设备/合集/合并组/年份/月/地点/主题/影调/评分/色标）
├─ 中：网格（卡片双击=预览，右键=菜单）
│   └─ 右键：评分 / 色标 / 选用废片 / 合并组 / 仅删除 JPEG / 删除到回收站 / 合集 / AI / 资源管理器
├─ 右：检视面板（编辑评分/城市/主题/影调/关键词…）
└─ 空态动作：扫描（无素材）/ 清空筛选（有素材但筛空）

云相册 CloudPage（原云同步合并）
├─ 浏览卡片：目标选择 / 面包屑 / 上一级 / 刷新 / 全选 / 下载到素材库 / 上传所选素材
│   ├─ 网格：缩略图（Range 生成）、选中框、双击进入文件夹或看大图
│   └─ 失败：错误条 + 重试（保留当前目录）
├─ 同步卡片：目标列表 / 差异预览 / 立即同步 / 按分类上传 / 暂停取消 / 报告 / 诊断
└─ 设置入口：目标增删改、WebDAV 诊断

设置 SettingsPage
├─ 外观（Fluent / 明暗）
├─ 媒体库（添加/移除/分库开关/拖拽文件类型）
├─ 缓存 / AI / 云 / LUT / 维护工具
└─ 关于

详情/预览：双击卡片 → PreviewOverlay（缩放、上一张/下一张、Esc 关闭）
```

## Android

```
素材库 LibraryScreen
├─ 顶栏：搜索 / 排序菜单 / 筛选 / 云相册 / 设置
├─ 快捷 chips：只看 RAW / 只看 Log / 选用 / 废片
├─ 网格：缩略图 + 角标（RAW/LOG/视频）；长按多选；点击详情
├─ 详情 Sheet：封面（点=全屏）/ 分享 / 用其他方式打开 / 评分 / 色标 / 选用 / 调色 / 设备/型号/拍摄时间/经纬度 / 城市/标题/主题/影调/关键词 / 保存
├─ 筛选 Sheet：类型/格式/设备/地点/年份/主题/影调/色标/评分/选用/调色
├─ 批量 Sheet：评分/色标/选用/调色
└─ 空态：去添加素材 / 清空筛选

云相册 CloudAlbumScreen
├─ 顶栏：返回 / 账号 / 刷新
├─ 面包屑：/路径 · 上一级 · 全选
├─ 网格：缩略图 / 文件夹 / 勾选
├─ 底部：下载（到本机）/ 上传（素材库选中素材）
└─ 失败：错误色状态 + 重试

设置 SettingsScreen
├─ 媒体库（系统相册/SAF/路径/root 开关）
├─ 交换文件（导入/导出）
├─ 外观（明暗/动态取色/密度）
└─ 关于
```

## 关键跳转与返回

| 从 | 动作 | 到 | 返回后 |
| --- | --- | --- | --- |
| 素材库 | 双击卡片 | 预览 | 回到原筛选与滚动位置 |
| 素材库 | 长按卡片 | 多选态 | 取消后恢复杂项 |
| 云相册 | 双击文件夹 | 子目录 | 上一级保留路径 |
| 云相册 | 下载/上传 | 后台任务 + 状态行 | 导航不丢 |
| 设置 | 添加媒体库 | 系统选择器 | 返回后列表刷新 |
| Android 详情 | 保存 | 关闭 Sheet | 列表卡片更新 |

## 状态矩阵（供 UE 图标注）

- 页面态：加载中 / 空 / 有数据 / 筛选空 / 错误。
- 组件态：默认 / 悬停（桌面）/ 按下 / 选中 / 禁用 / 加载中 / 错误。
- 不可逆操作：删除（确认）、解散合并组（确认）、覆盖导入（需选择策略）。
- 平台差异：Windows 右键菜单 + 键盘快捷键；Android 长按 + Sheet；macOS 右键 + 快捷键（以 macOS 仓库为准）。
