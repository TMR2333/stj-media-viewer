## 结论

基础可用，但**失败与异常状态的引导不足**：权限被拒、云相册失败、保存失败都没有"下一步"。本次修 5 项，均为页面五态（`ui-walkthrough/references/page-states.md`）与错误恢复的要求。

## 发现

### A1 空状态只有说明、没有动作（P1，已修）
- 位置：`ui/LibraryScreen.kt` 空态、`ui/Components.kt#EmptyState`
- 证据：无素材时提示"点右下角「扫描」或去设置"，但空态里没有按钮；筛选无结果时提示"试试重置"但没有重置入口（要开筛选面板）。
- 预期：空态给一个能立刻完成的动作。
- 修复：`EmptyState` 支持 `actionText/onAction`；无素材→「去添加素材」进设置；筛选无结果→「清空筛选」直接 `resetFilter()` 并退出搜索。
- 复验：清空库启动 → 点「去添加素材」到设置；筛到 0 条 → 点「清空筛选」列表回来。

### A2 权限被拒后静默（P1，已修）
- 位置：`MainActivity.kt` 权限请求
- 证据：`RequestMultiplePermissions` 回调为空，拒绝后无任何提示；用户只会觉得"没有素材"。
- 预期：说明为什么需要 + 提供去系统设置授权的入口。
- 修复：记录拒绝状态并弹窗：「需要媒体权限才能扫描素材」+「去设置授权」打开应用详情页 +「稍后」。
- 复验：全新安装拒绝权限 → 弹窗出现；点「去设置授权」跳到系统应用设置。

### A3 云相册失败无重试（P1，已修）
- 位置：`cloud/CloudAlbumViewModel.kt`、`cloud/CloudAlbumScreen.kt`
- 证据：连接/列目录失败只写 `status` 文本，无重试按钮，状态与成功态同色。
- 修复：状态增加 `error` 字段；失败时状态红色、显示「重试（原因）」按钮；成功后清空。
- 复验：错误账号 → 连接失败红字 + 重试；改对账号 → 重试成功。

### A4 详情保存失败无反馈（P1，已修）
- 位置：`vm/LibraryViewModel.kt#saveAsset`
- 证据：`db.updateAsset` 与 XMP 写入没有 try/catch，异常会让协程崩溃；成功才有「已保存」。
- 修复：`runCatching` 包裹，失败提示「保存失败：原因」（snackbar），成功仍「已保存」。
- 复验：把库目录设只读/文件被占用 → 保存 → 出现失败提示且不崩。

### A5 长状态文本无限行（P2，已修）
- 位置：`cloud/CloudAlbumScreen.kt`
- 修复：`maxLines=2` + Ellipsis；错误颜色区分。

### A6 触控目标与阅读顺序（P2，未验证）
- 证据：图标按钮用 `IconButton`（默认 48dp）但卡片内 Checkbox 与网格长按目标未测；TalkBack 阅读顺序未核。
- 状态：未验证；列入后续：给缩略图卡片加 `semantics { contentDescription = 文件名 + 状态 }`，Checkbox 补描述，网格用 `traversalIndex` 或自然顺序复核。

### A7 平板/横屏（P2，未验证）
- 证据：网格 `GridCells.Adaptive(104.dp)` 自适应，但详情 sheet 在平板仍是底部弹层；未在 ≥600dp 宽度验收。
- 状态：未验证。

### A8 文案一致性（P3，部分修）
- 本次空态/权限/保存提示已按词表改写；待办：设置页与云相册的"云同步/云相册"历史叫法统一、错误提示统一三段式。
