## 文案策略卡（ux-writer 第一阶段）

**一句话定位**：给拍娃/拍风光、一次出几百上千张 RAW+JPG 的摄影爱好者，在 Windows / Android / macOS 上管理、筛选、标注、交付素材的本地素材库工具。

**用户三问**
- 已经懂什么：相机、RAW/JPG、Lightroom/Photoshop、云盘、EXIF；不懂"合并组/分组""索引库"这类内部叫法。
- 什么情境下用：坐在电脑前批量整理（Windows/macOS），或拍完在手机/平板上快速筛片（Android/iPadOS）。移动端字更少、动作更直接。
- 来几次：每天/每周用的工具，引导只在首次出现，之后让路。

**语气表**

| 原则 | 用词 | 详略 | 标点/格式 |
| --- | --- | --- | --- |
| 像摄影助手的操作提示 | 用摄影圈常用词（废片、选用、调色、导卡） | 一屏一件事，一句尽量一行 | 不用感叹号，不用"让我们" |
| 结果先说，原因后补 | 状态先给结论（"已保存""刷新完成：…"） | 只在失败时补原因与下一步 | 数量/大小用数字，不写"若干" |

**对象 / 动作 / 状态词表（节选）**

| 对象 | 动作 | 状态 |
| --- | --- | --- |
| 素材 | 扫描、刷新、筛选、批量编辑、删除到回收站 | 选用 / 废片 / 未标记 |
| 云相册 | 浏览、下载到素材库、上传所选素材、同步 | 已连接 / 连接失败 / 加载失败 |
| 地点 | 恢复、批量改 | 有地点 / 未分类（`未分类` 统一写法） |
| 合并组 | 打开、解散、设封面、移出 | 折叠 / 展开 |

**统一口径（本次检查确认）**
- 「未分类」不写"未设置/"无"；「废片」不写"废弃"。
- 按钮一律"动词+对象"：`下载到素材库`、`上传所选素材`、`刷新`、`清空筛选`。
- 错误提示三段式：**发生了什么 + 可做什么 + 重试入口**（如"列出云端目录失败：…｜重试"）。
- 不在界面解释实现（索引库、SQLite、线程、缓存键）——这些只进日志。

## 本次落地改动

### Windows（v1.30.0）
1. 云相册加载失败：新增错误条 InfoBar（标题+原因+「重试」按钮），不再只有一行灰字；成功后自动消失。
2. 云相册「下载到素材库」：未勾选时禁用，并给 tooltip 说明前置条件；「上传所选素材」补 tooltip（要先在素材库选中，含 XMP）。
3. 云相册状态行限 2 行省略，避免长异常把布局撑开。
4. 顶栏「刷新」增加 **F5** 快捷键，tooltip 里写明。
5. 浏览器式"后退/刷新"状态：云相册保留当前目录路径与选择逻辑（重试不丢路径）。

### Android（0.5.0）
1. 空状态补动作：无素材→「去添加素材」；筛选无结果→「清空筛选」。
2. 权限被拒：弹窗说明为什么需要、提供「去设置授权」，不再静默失败。
3. 云相册加载/连接失败：状态行变错误色、显示「重试」，并可继续操作其它入口。
4. 详情保存失败：捕获异常并在 snackbar 提示「保存失败：原因」，不再只成功才提示。
5. 长状态文案限 2 行省略。

### 未完成 / 待验证（明确标注）
- **键盘与读屏**：仅抽查了主要入口，未逐页核对 AutomationProperties/焦点顺序（Windows）与 TalkBack 阅读顺序（Android）。属"未验证"，不代表没问题。
- **200% 缩放 / 窄屏 320px**：未在真机/缩放环境实测。
- **性能**：未做 1 万张网格的帧率/内存实测协议（技能 V12 要求实机测量）。
- **完整审查（full）**：本次是 quick，只覆盖素材库、云相册、设置、详情四条核心旅程；未覆盖导入、转码、水印、AI 队列等子页面。

## 验收方法（对应两份 quick review）

- Windows：打开云相册 → 断网/错密码点刷新 → 出现错误条与「重试」；勾选前后「下载到素材库」启用态变化；按 F5 触发刷新进度。
- Android：拒绝权限 → 出现授权引导；筛选无结果 → 出现「清空筛选」并生效；断网进云相册 → 错误色状态 + 「重试」；详情保存失败（只读目录）→ snackbar 报错。
- 回归用例见 [`walkthrough-cases.md`](walkthrough-cases.md)。
