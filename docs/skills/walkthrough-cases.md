# UI 走查用例（ui-walkthrough 方法论）

对应技能：`ui-walkthrough`（页面五态、0/1/多、中断与异常、生命周期、视图与设备）。
范围：素材库、云相册、设置、详情。**标注「未验证」的项没有在真机/缩放环境实测**。

## 1. 素材库

| ID | 场景 | 步骤 | 预期 | 状态 |
| --- | --- | --- | --- | --- |
| L-01 | 0 条 | 空库启动 | 空态 + 可执行动作（Windows：扫描；Android：去添加素材） | 已修 |
| L-02 | 1 条 | 库里只有 1 张 | 网格居中/左对齐，筛选分面计数=1 | 未验证（视觉） |

| L-04 | 筛选无结果 | 搜索乱串/选互斥条件 | 空态 + 「清空筛选」；清空后恢复 | Android 已修；Windows 已有 |
| L-05 | 排序后 | 切评分降序再升序 | 顺序正确，箭头/文案同步 | 未验证 |
