# Android 验收清单（真机 / 模拟器）

> APK：`app/build/outputs/apk/release/app-release.apk`（签名：`STJ Media Viewer` / SHA-256 `628136d2…`）
> 目标设备：Android 8.0+（推荐 12+ 体验动态取色），arm64-v8a。

## 安装

```bash
adb install -r app-release.apk
adb shell am start -n com.stjarna.mediaviewer/.MainActivity
adb logcat -s STJ *:E
```

## 首次启动

- [ ] 弹出媒体权限请求（图片/视频），拒绝后仍能进入界面并提示去设置授权。
- [ ] 空状态显示「还没有素材 / 扫描」，右下角 FAB「扫描」可见。
- [ ] 设置页可进入，返回键回到素材库。

## 媒体来源（三选一，逐项验收）

**A. 系统相册**
- [ ] 设置 → 媒体库 → 「系统相册」→ 右上 FAB「扫描」。
- [ ] 扫描进度条推进，结束后网格出现缩略图；状态栏提示「扫描完成：N 张素材」。
- [ ] 照片按拍摄时间倒序；视频卡片有「视频」角标与首帧。

**B. SAF 文件夹**（相机卡 / SD 卡 / 网盘目录）
- [ ] 设置 → 「选择文件夹」→ 选 `DCIM` 或相册目录 → 返回后列表出现该库。
- [ ] 扫描后能读到 EXIF 时间/相机/GPS；缩略图正常。

**C. root 模式（可选）**
- [ ] 设置 → 打开「使用 root 获取更多权限」→ 状态显示「su 可用」。
- [ ] 「输入路径」填 `/sdcard/DCIM` → 扫描成功；详情修改评分后，用文件管理器确认同目录生成 `xxx.jpg.xmp`。
- [ ] 无 root 的设备打开开关应显示「当前没有 su 权限」，不崩溃。

## 素材库

- [ ] 网格自适应列数；设置里切 小/中/大 密度立即生效。
- [ ] 长按卡片进入多选，顶部标题变「已选 N 项」，底部出现 全选/取消。
- [ ] 多选 → 批量编辑：评分/色标/选用/调色写入成功；返回后卡片角标与评分更新。
- [ ] 单击卡片打开详情：大图、文件名、格式、尺寸、拍摄时间、设备。
- [ ] 详情修改：评分、色标、选用三态、调色、Log、城市（如「平遥」）、标题、主题（逗号分隔）、影调、关键词 → 保存后刷新。
- [ ] 搜索「平遥」/「Sony」能过滤出对应素材。
- [ ] 快捷 chips：只看 RAW / 只看 Log / 选用 / 废片 生效。
- [ ] 筛选面板：类型、格式、设备、地点（含「未分类」）、年份、主题（含「未填写」）、影调、评分、色标、选用状态；
      多选同组 OR、跨组 AND；「重置」恢复全部。

## 交换文件（与 Windows 互通）

- [ ] 在 Windows 导出 `STJ-设置与图片数据-*.json`，拷到手机。
- [ ] Android 设置 → 导入… → 选文件 → 弹出预览（来源版本/平台/匹配数/未匹配数/不含密钥）。
- [ ] 选「只填空字段」：匹配条数 > 0，已存在评分不被覆盖；再次导入显示「更新 0 / 跳过 N」。
- [ ] 选「覆盖已有值」：Windows 里的评分/城市/关键词写入手机侧对应素材。
- [ ] Android 设置 → 导出… → 存到下载目录 → 拿到 Windows 导入，匹配数与手机上一致。
- [ ] 导出文件全文搜索 `apiKey` / `password` / `DPAPI` 均无命中。

## 云相册（WebDAV）

- [ ] 素材库右上角云图标进入云相册；未配置时提示先填地址/账号。
- [ ] 填 123pan WebDAV 地址 + 账号密码 → 「连接」→ 显示「连接成功」并列出根目录。
- [ ] 进入含中文/空格路径的目录，面包屑正确；「上一级」可返回。
- [ ] 缩略图逐步出现（JPG/RAW）；RAW 不应触发整文件下载（观察流量/耗时）。
- [ ] 点 JPG 弹出大图预览；点 RAW 若为首帧不支持则提示（不崩溃）。
- [ ] 勾选 2 张 → 「下载」→ 提示已下载 N；素材库刷新后能看到，且能在系统相册看到副本。
- [ ] 素材库选中 2 张（含 XMP 的）→ 云相册 → 「上传」→ 云端目录出现原文件 + `.xmp`；刷新列表可见。
- [ ] 断网：连接/列表/下载/上传分别给出可读错误，恢复后可重试。
- [ ] 错误密码：提示 401/连接失败，不崩溃、不泄漏密码到日志。

## 外观

- [ ] Android 12+ 开启动态取色，主题色随壁纸变化；关闭后回到 STJ 琥珀/炭黑。
- [ ] 明暗模式：跟随系统 / 浅色 / 深色 立即生效。
- [ ] 大标题在滚动时折叠；底部 FAB 不遮挡最后一行卡片。

## 稳定性

- [ ] 10,000 张素材的相册：首屏 < 2s 出现缩略图，滚动不 ANR，内存不持续上涨。
- [ ] 扫描中断（切后台/旋转）不崩溃；再次扫描为增量（重复扫描不产生重复素材）。
- [ ] 旋转屏幕 / 切深色模式，筛选与选中状态不丢。
- [ ] `adb shell dumpsys meminfo com.stjarna.mediaviewer` 常驻 < 400MB（大相册浏览后）。

## 已知问题（预期行为）

- 没有内嵌预览的 RAW 显示占位图。
- 非 raw 的 HEIC 在个别 Android 8/9 设备上解码失败 → 占位。
- 未授予「所有文件访问」时，手动填写的 `/sdcard/...` 路径可能读不到，请改用 SAF 选择文件夹。
